About

[ WIFI MONITOR ]

Jio WiFi Data Tracker

A lightweight, dedicated network telemetry and traffic monitor engineered specifically for JioFiber and JioAirFiber home gateway routers.

• Platform Target: Optimized for Raspberry Pi Zero 2 W
• Preserved Direction Semantics: Router TX = Download, Router RX = Upload
• Storage Engine: SQLite 3 with Write-Ahead Logging (WAL)
• Architecture: Read-only monitoring with full credential isolation
• Timezone Standard: Asia/Kolkata (IST)
