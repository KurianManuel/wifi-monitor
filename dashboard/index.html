ABOUT JIO WIFI DATA TRACKER

JIO WIFI DATA TRACKER is a dedicated network telemetry and traffic monitor built specifically for JioFiber and JioAirFiber home gateway routers.

Key Architecture Highlights:

  • Zero-Overhead Target: Purpose-built for the Raspberry Pi Zero 2 W with minimal CPU and RAM usage.
  • Preserved Direction Semantics: Correctly maps router counter statistics (current_tx delta = download_bytes, current_rx delta = upload_bytes).
  • Local Storage: SQLite with Write-Ahead Logging (WAL) for safe, concurrent, long-running retention.
  • Strict Isolation: The dashboard communicates exclusively through a read-only Flask API. Credentials and router sessions are never exposed to the client.
  • Timezone Standard: All date and time representations are locked to Indian Standard Time (IST, Asia/Kolkata) with full 24-hour retention across midnight transitions.
